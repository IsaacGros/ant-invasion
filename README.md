# Ant Invasion

An interactive Android mobile bug-smasher game built in **Java** using **Android Studio (Android 4.4 KitKat)** as a solo development project.

**Repository:** `https://github.com/IsaacGros/ant-invasion`

## Overview

This project implements a mobile bug-smasher game built end-to-end as a solo developer, encompassing game mechanics programming, sprite and UI design, sound design, and debugging.

## Tools Used

- **Language & IDE:** Java, Android Studio (Android 4.4 KitKat)
- **Art & Audio:** Clip Studio Paint, Audacity

## Controls

- **Smash Ants:** Tap on-screen ants
